# DAXQO V1.0 单 APK

V1.0 把 Android 界面、PRoot、Ubuntu 用户态、Python 3.12、Codex 0.163.0、Motor、Trajectory Collector、邮件依赖和本地语音模型装进一个 ARM64 APK。首次打开完全从 APK 本地准备运行环境，不需要 Termux、厂商 Linux 或电脑；模型服务、邮件和短信等仍需相应网络或通信服务，本地语音识别在设备上运行。

## 发布构建

- APK：`dist/v1.0.0/DAXQO-1.0.0-arm64.apk`，525,139,916 bytes，versionCode 100，release/non-debuggable，ARM64，minSdk 26，targetSdk 35。
- SHA-256：`7b5641dd213b91a07e9ff698b4843017a8eeaeeff2633f01baddb8e81a1d3249`
- 包含 PRoot、Ubuntu、Python 3.12、Codex 0.163.0、Motor、Trajectory Collector、邮件依赖和本地 ASR 模型。rootfs 解包大小为 1,468,907,118 bytes。
- release APK 使用现有本机 Android debug keystore 名称对应的密钥签名，但关闭了调试。后续覆盖升级必须保管并继续使用同一私钥；更换密钥会阻止原位升级。

Windows 构建命令：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\build_v1.ps1 `
  -MotorSource "C:\src\DAXQO Motor" `
  -CollectorSource "C:\src\DAXQO Trajectory Collector" `
  -Release -Lint
```

## V0.7 功能延续

- 本机流式中文语音识别；转写为可编辑草稿，不会自动发送。
- 新对话使用独立工作区；支持对话成果文件和经授权的图片预览。
- 短信任务默认关闭，可信号码名单默认空。启用前需由用户授权并选择可用 SIM；手机系统仍决定短信等权限是否授予以及是否要求逐条确认。
- 普通邮件支持 Gmail、QQ 和网易；需用户配置邮箱、可信联系人并验证邮件身份。
- 手机控制遵循 Android 系统授予的权限和用户选择的控制模式。轨迹采集默认关闭。

V0.7 的语音草稿、任务工作区、成果交付、普通邮件、短信控制和手机授权边界继续沿用，详见 [V0.7 指南](V0.7.md)。此前 V0.x 版本记录继续保留，参见 [V0.5](V0.5.md)、[V0.6](V0.6.md)、[V0.6.2](V0.6.2.md) 和 [V0.7](V0.7.md)。

## 本地构建

开发构建需要本地 Motor、Trajectory Collector 源码仓库，以及已固定版本和哈希的离线素材目录。参数指向两个源码仓库根目录；脚本会分别读取其中的 `motor` 和 `trajectory` 子目录。

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\build_v1.ps1 `
  -MotorSource "C:\src\DAXQO Motor" `
  -CollectorSource "C:\src\DAXQO Trajectory Collector" `
  -InputDirectory ".\dist\deploy-cn\packages" `
  -Release -Lint
```

## 安装与升级

正式运行不依赖 Termux、厂商 Linux 环境或电脑；APK 内的环境与运行依赖可离线初始化。Android 系统仍控制运行时权限和用户确认；DAXQO 不会自行取得更高权限。云模型、邮件和短信等外部服务仍需网络或通信服务。STEPX Neo 用户首次安装后，需在系统设置中手动允许自启动、关联启动和后台运行，按返回保存并重新进入确认；系统不会允许 APK 替用户修改这些选项。

从旧 V0.x 外部 Linux 后台迁移时，先通过受管流程停止旧的 `18880` 和 `18882` 服务并保留旧数据，再安装 V1。不要通过卸载 App 或清除数据来迁移。已有 V1 升级应保留 `state` 和 `workspace`。
