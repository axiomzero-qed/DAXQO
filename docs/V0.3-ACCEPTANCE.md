## 兼容说明 / Compatibility notes

子智能体的 catalog v2 消息丢失问题与上游兼容讨论相关：[openai/codex#36586](https://github.com/openai/codex/issues/36586)。切换到 catalog v1 并关闭 search 后，新建会话按新协议配置运行；已有会话会保留创建时的协议配置，因此需要新建会话验证变更效果。

The catalog v2 subagent message-loss issue is related to upstream compatibility discussion: [openai/codex#36586](https://github.com/openai/codex/issues/36586). After switching to catalog v1 and disabling search, new conversations use the updated protocol configuration. Existing conversations retain the protocol configuration from their creation, so a new conversation is required to verify the change.

## 尚未验证与边界 / Unverified areas and limits

- 24 小时保活、长期高负载和长程上下文压力测试尚未完成。受控压缩检查不代表长期稳定性结论；默认压缩阈值已恢复为 32000 tokens、窗口恢复为 65536 tokens。

  24-hour uptime, sustained high-load operation, and long-context stress tests have not been completed. The controlled compaction check does not establish long-term stability; the default threshold was restored to 32000 tokens and the context window to 65536 tokens.
- 图片视觉理解尚未验证，能力取决于运行时和所选模型。

  Image understanding has not been verified; capability depends on the runtime and selected model.
- Android 只管理已经运行的 Linux 环境内的 DAXQO 服务；vendor 容器启动、唤醒和持续保活不受支持，也未验证。

  Android manages DAXQO services only inside an already-running Linux environment; starting, waking, and keeping the vendor container alive are unsupported and unverified.
- 本记录不包含任何真实任务原文或凭据。Android APK 为 debug 构建；正式发布签名由维护者管理。

  This record contains no real task text or credentials. The Android APK is a debug build; maintainers manage the signing key for official releases.
