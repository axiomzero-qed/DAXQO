# DAXQO V1.0.1

V1.0.1 保留 V0.7 能力，并为微信操作增加用户控制门禁。正式 APK 为 [DAXQO-1.0.1-arm64.apk](../dist/v1.0.1/DAXQO-1.0.1-arm64.apk)：versionCode 101、versionName 1.0.1、non-debuggable、525,144,012 bytes，SHA-256 `0fe08bf4e1020b89715091849b4fd98ae94f435cda843c32074b4698f71c8581`。

## 微信操作门禁

微信操作默认关闭；微信本地配置缺失或损坏时也按关闭处理。用户如需开启，必须在手机控制页阅读封号及永久封号风险提示，并亲自勾选确认。模型请求、full 模式、短信、邮件和任务都不能开启该设置，也不能代替用户确认。

门禁统一作用于 DAXQO 的 Android 原生控制、直接 HTTP 控制接口和 Motor。操作检查覆盖 full 模式读写、微信启动、分屏与浮窗、IME、launcher 节点和坐标、父行微信标签、缓存动作重放、租约撤销、截图回调及轨迹采集。关闭开关不会撤回已经提交给 Android 的动作。允许操作也不会解除 Trajectory Collector 独立执行的隐私过滤。

该门禁只覆盖 DAXQO 控制接口。它不能阻止用户手动操作微信、其他应用自行跳转，或身份未知的换壳应用改变包名；相同应用 UID 下运行的恶意代码也不受此门禁隔离。因此这不是系统级防火墙。

验收证据保存在 [`dist/v1.0.1/acceptance`](../dist/v1.0.1/acceptance)。本轮未重发 SMS/email、未碰小米，也没有重跑云模型全闭环。V1.0.1 新安装无需 Termux 或命令行；用户仍需配置自己的模型 API key，并按系统提示授予所需权限。

本次验收不代表所有 Android 设备都通过。系统授权由用户本人完成，其他厂商可能需要不同设置。关闭门禁不会撤回已提交给 Android 的动作；其他 App 自行跳转、换壳未知包和相同 UID 恶意代码不受系统级隔离。Trajectory Collector 的隐私过滤保持独立。
