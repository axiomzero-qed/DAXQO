# DAXQO V1.0.1

V1.0.1 保留 V0.7 能力，并为微信操作增加用户控制门禁。发布 APK 预期路径为 `dist/v1.0.1/DAXQO-1.0.1-arm64.apk`；最终体积和 SHA-256 待发布构建后补充。

## 微信操作门禁

微信操作默认关闭。微信本地配置缺失或损坏时也按关闭处理。用户如需开启，必须在手机控制页阅读封号及永久封号风险提示，并亲自勾选确认。模型请求、full 模式、短信、邮件和任务都不能开启该设置，也不能代替用户确认。

门禁统一作用于 DAXQO 的 Android 原生控制、直接 HTTP 控制接口和 Motor。关闭时，这些入口会检查应用启动、分屏与浮窗、IME、launcher 节点及坐标操作、父行标签、缓存动作重放、租约撤销、截图回调和轨迹采集中的微信目标。关闭开关不会撤回已经提交给 Android 的动作。允许微信操作也不会解除 Trajectory Collector 独立执行的隐私过滤。

该门禁只覆盖 DAXQO 控制接口。它不能阻止用户手动操作微信、其他应用自行跳转，或身份未知的换壳应用改变包名。相同应用 UID 下运行的恶意代码不受此门禁隔离；它不是系统级防火墙。

## 验收状态

以下验收仍待补充，当前不应视为通过：

- 15 项纯策略检查。
- 受保护与普通的无账号 fixture 检查。
- 手机控制页重复 owner 检查。
- 真实微信仅做负向检查，不发送消息。

V0.7 能力继续保留。V1.0 离线运行及 Neo 验收历史见 [V1.0 指南](V1.0.md) 和 [V1.0 Neo 验收记录](V1.0-NEO-ACCEPTANCE.md)。
