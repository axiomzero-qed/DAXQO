## 范围与限制 / Scope and limitations

- 当时的运行环境依赖终端已有的 Linux 容器。App 可管理 DAXQO 后端，不能独立创建或唤醒厂商容器。

  The runtime environment at that time depended on the terminal app's existing Linux container. The app can manage the DAXQO backend but cannot independently create or wake the vendor container.
- 本次包含任务执行期间追加消息及多次服务重启，没有进行数小时、全天后台运行或整机重启验收。

  This run covered appending messages during task execution and multiple service restarts, but did not validate multi-hour or all-day background operation or a full-device reboot.
- 当时尚未实现完整 Android 系统自动化、语音和厂商无关的 Linux 安装环境。

  Full Android system automation, voice features, and a vendor-independent Linux installation environment were not implemented at that time.
- 通用 Linux 安装器已检查官方运行时元数据和离线校验流程；当时尚未在另一台全新 Linux 设备完成端到端安装验收。

  The general Linux installer had checked official runtime metadata and offline verification; an end-to-end installation on another clean Linux device had not yet been accepted at that time.
