# DAXQO V1.0：STEPX Neo 验收

日期：2026-10-26。设备：STEPX Neo / PZ261A，Android 16，ARM64，4 KB 内存页。此次没有操作小米手机。

交付包为 `dist/v1.0.0/DAXQO-1.0.0-arm64.apk`，版本 `1.0.0` / versionCode `100`，包名 `io.daxqo.app`。APK 为关闭调试的 release 构建，已安装在 Neo；沿用旧版签名以支持覆盖升级。

## 单 APK 与安装体验

PRoot、Ubuntu 用户态、Python 3.12、Codex 0.163.0、Motor、Trajectory Collector、邮件依赖和本地语音模型均在 APK 中。新手机首次打开时只做本机展开和设备配置，不运行联网包管理器，不要求客户安装 Termux 或操作命令行。

APK 大小为 **525,139,916 bytes（约 525 MB）**，SHA-256：

```text
7b5641dd213b91a07e9ff698b4843017a8eeaeeff2633f01baddb8e81a1d3249
```

运行环境文件展开约 **1.47 GB**；实际占用还包括 APK、Android 文件系统开销、用户工作区和升级保留的旧环境。首次空环境测试用时 **26.02 秒**。发布构建覆盖安装后也在无默认网络连接时完成本机环境准备。

新客户仍需填写自己的模型 API Key，并按需允许麦克风、通知、短信和辅助功能等系统权限。云模型及邮件需要网络，短信需要移动通信服务。本地语音识别及环境展开不需要网络。

Neo 的后台设置路径为“系统设置 → 应用信息 → DAXQO → 耗电和后台 → 手动管理”，开启“允许自启动”“允许关联启动”“允许后台运行”，**按返回保存，再进入确认**。设置未保存时 StepOS 会拦截开机广播；保存后实际重启已自动恢复运行。这些系统权限不能预先写入 APK。

## 回归与边界

Windows 后端执行 258 项测试，跳过 13 项；WSL 后端执行 258 项，跳过 28 项；构建脚本执行 59 项，跳过 5 项，其余通过。Android 构建、Lint、主机回归、APK 内容校验及签名校验通过。跳过项不算通过；远程 CI 尚未运行。

V0.7 的语音草稿、独立任务工作区、成果交付、短信控制、邮件、定时任务及手机控制代码和配置继续保留。本轮没有重新发送真实短信或邮件，不能据此宣称全部提供商通信闭环重测通过。真实设备范围仅为上述 Neo，其他机型仍需适配验收。

通知栏提供停止运行入口；用户停止、系统强行停止或厂商后台限制可能中断服务。常驻后台会增加耗电，本次没有进行 24 小时保活、长期耗电或大规模客户兼容性测试。

旧外部 Linux 版本覆盖安装不会自动导入其私有数据；迁移需停止旧后台并显式转移配置与工作区。本次 Neo 已完成迁移，旧数据源保留。客户迁移不要卸载 App 或清除数据。
